> ⚠️ **Прототип.** Калькуляторы риска (SCORE2 / Framingham) демонстрационные и требуют
> клинической валидации. Приложение **не устанавливает диагноз** и не заменяет
> консультацию врача. Демонстрационный вход без реальной аутентификации.

CardioGuard — дипломный клинико-технологический проект для непрерывного самоконтроля
кардиометаболического здоровья, повышения приверженности лечению и превентивного снижения
риска ССЗ. Репозиторий содержит **две реализации**:

| Каталог | Стек | Статус |
|---------|------|--------|
| **[`mobile/`](mobile/)** | React Native · Expo SDK 55 · TypeScript | 🟢 Активная разработка — Android · iOS · Web |
| **[`app/`](app/)** | Kotlin · Jetpack Compose · MVVM | 📦 Оригинальный Android-прототип (первоисточник логики) |

## ✨ Возможности

Две роли — **пациент** и **врач/исследователь** — с переключением в один тап.

| # | Модуль | Кратко |
|---|--------|--------|
| 1 | **Профиль / медкарта** | Паспортно-клинические данные, анамнез, факторы риска, цели |
| 2 | **Мониторинг показателей** | АД, ЧСС, вес, ИМТ, глюкоза, сон, активность; графики динамики |
| 3 | **Оценка риска ССЗ** | 10-летний риск по валидированным **SCORE2 (ESC 2021)** и **Framingham** |
| 4 | **Приверженность + напоминания** | Тайм-шедулинг приёма, расчёт комплаентности, локальные уведомления |
| 5 | **Психоэмоциональный мониторинг** | Еженедельный опрос самочувствия, классификация состояний |
| 6 | **Интеллектуальная аналитика и прогноз** | Тренды (регрессия + EWMA) и прогноз рисков — **на устройстве, без облака** |
| 7 | **Раннее предупреждение** | 9 клинических триггеров → сигнальные карточки |
| 8 | **Персональные рекомендации** | Движок на основе риска, приверженности и динамики |
| 9 | **База знаний** | Образовательные статьи по профилактике |
| 10 | **Группы и когортная аналитика** | Деперсонализированные сводки по группам наблюдения (роль врача) |
| 11 | **Аналитическая панель + индекс здоровья** | Композитный индекс здоровья 0–100 с разбивкой по факторам |

Дополнительно: **PDF-отчёт для врача** (печать + шеринг), тёмная/светлая тема, настройки
плотности и скругления интерфейса, доступность (a11y), полная локализация **ru / uz**.

## 🧱 Технологии (mobile/)

- **Expo SDK 55** · React Native 0.83 · React 19 · **TypeScript** (strict)
- **Expo Router** — file-based навигация (группы вкладок patient/doctor)
- **Zustand** — состояние; **AsyncStorage** — локальное хранение; **Zod** — валидация данных
- **react-i18next** + expo-localization — локализация ru / uz
- **react-native-svg** — графики и кольцевые индикаторы; **lucide-react-native** — иконки
- **expo-notifications / expo-print / expo-sharing / expo-haptics** — нативные функции
- **Jest** (jest-expo) + Testing Library — **206 тестов**, GitHub Actions CI

## 🚀 Быстрый старт

```bash
cd mobile
npm install
npm run web        # веб-превью на http://localhost:8081
npm test           # 206 тестов
npm run typecheck  # tsc --noEmit
```

### 📱 Запуск на реальном устройстве (iPhone / Android)

Веб не задействует нативные функции (уведомления, PDF, haptics) — их проверяют на устройстве.

```bash
cd mobile && npx expo start      # затем сканировать QR
```

- **Android (Expo Go):** сканировать QR из терминала приложением Expo Go.
- **iOS:** версия Expo Go должна поддерживать **SDK 55**. Если в App Store доступна более
  старая — поставьте Expo Go через [TestFlight](https://testflight.apple.com/join/GZJxxfUU)
  и сканируйте QR системной «Камерой».
- Телефон и ПК — в одной сети (или раздача интернета с телефона).

Полное руководство и сборка **development build (EAS)** — в [`mobile/README.md`](mobile/README.md).

## 🏛 Архитектура

Однонаправленный поток данных, домен изолирован от UI и инфраструктуры:

```
Действие пользователя → Zustand-стор (side-effects: даты, id, I/O)
        → чистые доменные движки пересчитывают риск / рекомендации / алерты / аналитику
        → UI реактивно обновляется → состояние персистится (AsyncStorage + Zod)
```

**Принципы:** канонические enum-коды в данных (подписи — через i18n, поэтому ru/uz
переключаются без изменений логики); все клинические пороги — именованные константы
(нет magic values); чистые функции домена детерминированы и покрыты тестами.

## ✅ Качество

- **206 тестов** (`npm test`) — домен (калькуляторы, оба движка, mood, insights,
  healthIndex, cohort/prng), слой данных (REST-адаптер с retry/timeout, Zod-валидация),
  стор-интеграция, UI-примитивы и экраны. TypeScript strict, без `any`.
- **Zod-валидация** персиста и внешних данных: повреждённое хранилище деградирует к
  чистому пересиду, а не падает; глобальный **Error Boundary** перехватывает сбои UI.
- Доступность: роли/метки на интерактиве, доступные графики, контраст AA в обеих темах.
- Исправлены 2 клинических бага исходной Kotlin-версии (зазоры классификации ИМТ и выбор
  худшей оси для АД) — задокументированы в `mobile/src/domain/calculators.ts`.
